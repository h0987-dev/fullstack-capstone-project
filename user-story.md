# GiftLink user stories

- As a visitor, I want to browse gifts so I can find inspiration.
- As a visitor, I want to search by keyword so I can narrow results.
- As a visitor, I want to filter by category so I can shop for a specific person.
- As a registered user, I want to create an account so I can save my identity.
- As a registered user, I want to log in securely so I can access my profile.
- As a user, I want to view gift details so I can make an informed choice.
- As a user, I want to comment on a gift so I can share context.
- As a user, I want to update my profile so my information stays current.
